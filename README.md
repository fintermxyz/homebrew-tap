# fintermxyz Homebrew Tap

```bash
brew install fintermxyz/tap/prism
```

| Formula | Description |
|---------|-------------|
| [`prism`](https://github.com/fintermxyz/prism) | ✨ Neon terminal control panel that toggles macOS background noise |

## Casks

```bash
brew install --cask fintermxyz/tap/terminal
```

| Cask | Description |
|------|-------------|
| [`terminal`](https://github.com/fintermxyz/terminal) | GPU-accelerated macOS terminal with LuaJIT modules, built-in viewers and clickable file links |
